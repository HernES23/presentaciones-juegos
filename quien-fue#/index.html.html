Final del juego

💩
💩
💩
¡Alguien perdió!

El juego termina cuando alguien acumula 3 fichas:

  • Ese jugador pierde.
  • Gana quien tenga menos fichas.
  • Partidas cortas: varias rondas seguidas.
  • Ideal para cerrar una noche de juegos.

Para disfrutarlo más

  • Ideal para familias con niños de 6+ años.
  • Excelente en grupos de 4-6 personas.
  • Juega varias rondas: cada partida dura 15 min.
  • Para adultos: añade reglas como no repetir animales.
  • Modo silencio: solo gestos, mucho más caótico.
  • Recomendado al Spiel des Jahres 2019 (infantil).
